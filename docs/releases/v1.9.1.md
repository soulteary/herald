## Compatibility and upgrade

The service API, configuration keys and persisted record formats are unchanged by this dependency refresh. Go remains 1.27.4. The release also includes the already-merged HTTP-listener error logging fix and test/operational dependency updates since v1.9.0. middleware-kit v3.0.8 includes the Fiber rate-limit key ownership fix; request-buffer reuse no longer changes retained limiter keys. This does not change the net/http adapter API.

Back up configuration and retain the previous exact program/image before deployment. No session, challenge, TOTP or cache-record migration is introduced by this patch. Validate the actual configured authentication/delivery path in staging. To roll back an SDK consumer, restore the complete previous go.mod and go.sum and rebuild: downgrading one module alone can retain newer requirements through Go minimal version selection.

This release also includes dependency, container and workflow maintenance already merged since v1.9.0; exact runtime requirements are recorded in go.mod/go.sum. Redis-backed services retain their existing go-redis v9.24.0 requirements from main; review retry, timeout and pool settings when upgrading from an older published deployment.
